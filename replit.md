# Xưởng Máy Gỗ Việt

E-commerce showroom website for Vietnamese woodworking machinery distributor.
Public storefront in Vietnamese + admin panel for managing products and articles.

## Stack

- **Backend** (`artifacts/api-server`): Express + Drizzle ORM + PostgreSQL.
- **Frontend** (`artifacts/web`): React + Vite + Tailwind + shadcn/ui + wouter.
- **Contract**: OpenAPI (`lib/api-spec`) → React Query hooks (`lib/api-client-react`) generated by Orval. Always run `pnpm --filter @workspace/api-spec run codegen` after editing the spec.
- **Auth**: Session-token based (random 256-bit token in `admin_sessions` table). Sent via `Authorization: Bearer <token>`. Default admin: `admin` / `admin123` (seeded on startup).

## Architecture

### Backend (`artifacts/api-server/src/`)
- `lib/auth.ts` — `requireAdmin` middleware uses `res.locals.admin` (we don't augment Express types).
- `lib/serializers.ts` — converts DB rows to API DTOs (handles numeric → number, JSON arrays).
- `lib/seed.ts` — `seedIfEmpty()` is invoked from `index.ts` on startup. Seeds 1 admin, 6 products, 3 posts.
- `routes/` — `auth`, `products`, `posts`, `home`, `admin` (CRUD for products + posts + stats).
- DB schema in `lib/db/schema.ts`. Numeric columns are stored as strings in Drizzle; convert in serializers.

### Frontend (`artifacts/web/src/`)
- `lib/api.ts` — calls `setAuthTokenGetter` to inject Bearer token from `localStorage["xmgv_admin_token"]`.
- `lib/format.ts` — `formatVnd`, `formatDate`, `slugify`.
- `App.tsx` — wouter routes with `WouterRouter base={import.meta.env.BASE_URL}`. Public routes use `PublicLayout`, admin routes wrapped in `RequireAuth` + `AdminLayout`. Critically, `/admin/san-pham/moi` and `/admin/bai-viet/moi` MUST be declared before `:id` routes.
- Generated hooks: `useGetHomeSummary`, `useListProducts`, `useGetProductBySlug`, `useListPosts`, `useGetPostBySlug`, `useListCategories`, `useAdminLogin`, `useGetCurrentAdmin`, `useGetAdminStats`, `useListAdminProducts`, `useCreateProduct`, `useUpdateProduct`, `useDeleteProduct`, `useListAdminPosts`, `useCreatePost`, `useUpdatePost`, `useDeletePost`.
- Mutations: `mutate({ id, data })` for update/delete; `mutate({ data })` for create.
- When passing custom `query` options to a generated hook, you MUST also include `queryKey: getXxxQueryKey()` (full UseQueryOptions, not partial).

### Routing (Vietnamese URLs)
- Public: `/`, `/san-pham`, `/san-pham/:slug`, `/tin-tuc`, `/tin-tuc/:slug`, `/gioi-thieu`, `/lien-he`.
- Admin: `/admin/login`, `/admin`, `/admin/san-pham`, `/admin/san-pham/moi`, `/admin/san-pham/:id`, `/admin/bai-viet`, `/admin/bai-viet/moi`, `/admin/bai-viet/:id`.

## Theme
Wood/amber palette in `src/index.css`: primary `28 80% 35%` (warm amber), dark sidebar `25 25% 12%`, cream background. Replaced the default red placeholders.

## Dev commands
- Restart workflows via the `restart_workflow` tool — never run `pnpm dev` from the repo root.
- `pnpm --filter web run typecheck` — frontend TS check.
- `pnpm --filter @workspace/api-server run typecheck` — backend TS check.
- `pnpm --filter @workspace/api-spec run codegen` — regenerate React Query hooks + Zod after spec changes.

## Notes
- Frontend free tier: design subagent unavailable, so frontend was hand-built with shadcn/ui primitives.
- Only one user-facing artifact (web). API server is internal.
- Logout in admin layout clears localStorage token and reloads.
- After login, the page does a full reload (`window.location.href`) so the API client picks up the new token getter result.
